Web Generations

The Web has evolved through generations, each bringing new capabilities and technologies.

GenerationEraFocus
Web 1.01991–2004Static, read-only pages
Web 2.02004–presentInteractive, user-generated content
Web 3.0EmergingSemantic, decentralised
Web 4.0FutureIntelligent, ambient, AI-driven

Key idea: Each generation added new capabilities to how we use the Web.

Web 1.0 — The Static Web (1991–2004)

Web 1.0 is the earliest phase of the World Wide Web. Pages were static HTML files, read-only, and created by a small number of website owners. Users could only consume content — there was no way to comment, post, or interact.

Characteristics

  • Static HTML pages — content didn't change without manual updates
  • No user-generated content; visitors could only read
  • No databases — pages stored as individual files on servers
  • Basic navigation: hyperlinks and simple forms only
  • Examples: Early Yahoo directory, GeoCities personal pages

Web 2.0 — The Social Web (2004–Present)

Web 2.0, a term popularised by Tim O'Reilly in 2004, describes the shift to a participatory Web. Users became creators — posting, sharing, commenting, and collaborating. This era gave us social media, blogs, wikis, and cloud applications.

Key Technologies

AJAX, JavaScript frameworks (React, Angular), REST APIs, CSS3, HTML5, mobile web.

Key Characteristics

Dynamic pages, user accounts, social networks, real-time updates, cloud storage, e-commerce.

Business Model

"Data is the new oil." Platforms monetise user data through targeted advertising (Google, Meta).

Examples

YouTube, Wikipedia, Facebook, Twitter/X, Gmail, Google Docs, Amazon.

Web 3.0 — The Decentralised Web (Emerging)

Web 3.0 (also called Web3) is a vision of a decentralised internet built on blockchain technology, where users own their data and digital assets rather than corporations. It also covers the Semantic Web concept — data structured so machines can understand context and meaning.

Characteristics

  • Decentralisation — applications run on peer-to-peer networks, not corporate servers
  • Blockchain — distributed ledger ensuring transparency and immutability
  • Smart Contracts — self-executing code enforcing agreements without intermediaries
  • NFTs & Tokens — verifiable digital ownership of assets on the blockchain
  • DApps — decentralised applications running on networks like Ethereum
  • Examples: Ethereum, IPFS, Uniswap, Filecoin, Polkadot

Web 4.0 — The Intelligent Web (Emerging)

Web 4.0 is the next conceptual generation — an ultra-intelligent and ubiquitous Web that deeply integrates with physical reality. It combines Artificial Intelligence, the Internet of Things (IoT), extended reality (XR), and ambient computing to create a Web that is proactive, predictive, and embedded in everyday life.

AI Integration

AI agents act on behalf of users, automating tasks and making decisions proactively. Think intelligent assistants that understand context deeply.

IoT Convergence

Billions of connected devices — smart homes, wearables, vehicles — exchange data continuously with Web services.

Ambient Computing

Technology fades into the background. Interactions happen through voice, gesture, and sensors rather than screens.

Digital-Physical Merge

AR/VR, digital twins, and spatial computing blur the boundary between the digital and physical worlds.
