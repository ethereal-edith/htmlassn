Web Browsers

A web browser is a software application that allows users to access, retrieve, and view resources on the World Wide Web. It acts as the client in the client-server model. Browsers send HTTP/HTTPS requests to web servers and render (display) the HTML, CSS, and JavaScript they receive back.

What a Browser Does

  • Resolves domain names via DNS lookups
  • Sends HTTP/HTTPS requests to web servers
  • Receives and parses HTML documents (the DOM)
  • Applies CSS stylesheets to render visual layouts
  • Executes JavaScript for dynamic behaviour
  • Manages cookies, caches, and local storage
  • Handles security (TLS, same-origin policy, CORS)

Google Chrome

Most popular browser (65%+ market share). Uses the V8 JavaScript engine and Blink rendering engine.

Mozilla Firefox

Open-source browser by Mozilla. Uses the SpiderMonkey JS engine and Gecko rendering engine.

Apple Safari

Default on Apple devices. Uses the WebKit engine. Optimised for macOS and iOS performance.

Microsoft Edge

Microsoft's browser, rebuilt on Chromium (2020). Replaced Internet Explorer.

Web Servers

A web server is both the hardware (physical/virtual machine) and software that stores, processes, and delivers web content to clients over the Internet. When a browser sends a request, the web server handles it and returns the appropriate resource — an HTML page, an image, JSON data, or a file.

What a Web Server Does

  • Listens for incoming HTTP/HTTPS requests (on ports 80 and 443)
  • Serves static content directly: HTML, CSS, images, PDFs
  • Passes requests to application servers for dynamic content (e.g., database queries)
  • Handles load balancing, caching, and SSL termination
  • Logs requests, errors, and access events
  • Enforces access controls and redirects

Apache HTTP Server

The most historically popular open-source web server. Highly configurable via .htaccess files.

Nginx

High-performance, lightweight server known for handling thousands of concurrent connections. Also used as a reverse proxy.

Microsoft IIS

Internet Information Services — Microsoft's web server for Windows environments.

Caddy

Modern server with automatic HTTPS via Let's Encrypt. Growing in popularity for simplicity.

Key Differences at a Glance

Role

Browser: Client — requests resources.
Server: Host — stores and serves resources.

Direction

Browser initiates requests.
Server responds to requests.

Location

Browser: Runs on the user's device (client-side).
Server: Runs in a data centre (server-side).

Output

Browser: Renders visual pages for the user.
Server: Returns raw data (HTML, JSON, files).
