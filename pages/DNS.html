Internet Protocol

Domain Name System (DNS)

The Domain Name System (DNS) is the Internet's phonebook. Every device on the Internet is identified by an IP address — a numerical label such as 142.250.200.46. Because humans find it difficult to remember strings of numbers, DNS was introduced to map easy-to-remember domain names (like google.com) to their corresponding IP addresses.

DNS was designed by Paul Mockapetris and first described in 1983 in RFC 882 and RFC 883. It is a hierarchical, decentralised naming system that operates across a worldwide network of servers.

How DNS Works

When you type a URL such as www.example.com into your browser, the following steps occur:

  1. Your browser checks its local DNS cache. If the IP is cached, no further lookup is needed.
  2. If not found, the query goes to your Recursive Resolver (usually provided by your ISP or a service like Google's 8.8.8.8).
  3. The resolver contacts a Root Name Server, which directs it to the correct Top-Level Domain (TLD) server (e.g., .com).
  4. The TLD server points to the Authoritative Name Server for the specific domain.
  5. The authoritative server returns the IP address, which the resolver caches and returns to your browser.

Key DNS Concepts

  • A Record — maps a domain name to an IPv4 address
  • AAAA Record — maps a domain name to an IPv6 address
  • CNAME Record — creates an alias from one domain to another
  • MX Record — specifies the mail server responsible for accepting emails
  • TTL (Time To Live) — how long a DNS record is cached before it expires
  • DNS over HTTPS (DoH) — encrypts DNS queries for greater privacy

DNS Hierarchy

Root Level

The top of the DNS hierarchy. There are 13 logical root name server addresses managed by ICANN.

Top-Level Domain (TLD)

Extensions such as .com, .org, .net, .ke. Each is managed by a designated registry.

Second-Level Domain

The name registered by an individual or organisation, e.g., google in google.com.

Subdomain

A prefix added before the domain, e.g., mail.google.com or docs.google.com.

Why DNS Matters

Without DNS, navigating the Web would require memorising the IP address of every website you visit. DNS provides a user-friendly, scalable addressing system that underpins virtually all Internet communications. It also enables features like load balancing, email routing, and content delivery networks (CDNs).
