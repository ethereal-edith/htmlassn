Multitier Architecture

Multitier architecture divides an application into layers so each part has a clear job.

TierRoleExample
PresentationUser interfaceBrowser
LogicBusiness rulesApplication server
DataStores informationDatabase

Key idea: separating layers makes systems easier to build and manage.
