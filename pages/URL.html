URL Structure

A URL (Uniform Resource Locator) is the address of a webpage or resource on the Internet.

ComponentMeaningExample
ProtocolHow to access the resourcehttps://
DomainWebsite addressexample.com
PathLocation of page on server/pages/about
QuerySearch parameters?id=123

Key idea: A URL tells the browser where to find a resource and how to fetch it.

Anatomy of a URL

Consider the full URL: https://www.example.com:8080/products/shoes?color=red&size=42#details

Scheme / Protocol

https:// — Specifies the protocol to use. Common schemes: http, https, ftp, mailto, file.

Subdomain

www — A prefix identifying a specific server within the domain. Not always present.

Domain Name

example.com — The human-readable name of the website, resolved by DNS to an IP address.

Port

:8080 — Specifies the network port. Omitted when using defaults (80 for HTTP, 443 for HTTPS).

Path

/products/shoes — The location of the specific resource on the server, similar to a file path.

Query String

?color=red&size=42 — Optional parameters passed to the server. Begins with ?, parameters separated by &.

Fragment / Anchor

#details — Refers to a specific section within the page. Processed entirely by the browser, not the server.

Top-Level Domain (TLD)

.com — The suffix of the domain. Examples: .com, .org, .ke, .edu, .gov.

URL Best Practices

Guidelines

  • Use lowercase letters in URLs — they are case-sensitive on most servers.
  • Use hyphens (-) to separate words in paths, not underscores or spaces.
  • Keep URLs short, readable, and descriptive for better SEO and usability.
  • Special characters must be percent-encoded — a space becomes %20, & becomes %26.
  • Always use HTTPS (not HTTP) for secure communication.
  • Avoid using query strings for content that should be indexed by search engines.
