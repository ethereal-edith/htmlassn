File Transfer Protocol (FTP)

FTP is used to upload and download files between a client and a server.

RoleExampleNote
File transferUpload website filesOften replaced by more secure options

Key idea: FTP moves files from one computer to another.

Admission Number: 220965

FTP uses a two-channel architecture:

Control Connection

Established on Port 21. Used to send commands and receive responses between client and server throughout the session.

Data Connection

A separate connection opened for each file transfer or directory listing. Uses Port 20 (active mode) or a negotiated port (passive mode).

Active Mode

The server initiates the data connection back to the client. Can be blocked by firewalls on the client side.

Passive Mode (PASV)

The client initiates both connections. More firewall-friendly and widely used today.

FTP Variants

Types of FTP

  • FTP (Plain) — Transfers data in plaintext; no encryption. Credentials can be intercepted.
  • FTPS (FTP Secure) — Adds TLS/SSL encryption to FTP. Also called FTP-SSL.
  • SFTP (SSH File Transfer Protocol) — Not traditional FTP; runs over SSH (Secure Shell) for fully encrypted transfers. Preferred in modern deployments.
  • FTPES — FTP with Explicit TLS; starts as plain FTP then upgrades to encrypted.
  • Anonymous FTP — Allows users to connect without a username/password, often used for public file distribution.

Common FTP Commands

FTP clients communicate with servers using text-based commands:

USER / PASS

Authenticate with a username and password.

LIST

List files and directories on the server.

RETR

Download (retrieve) a file from the server.

STOR

Upload (store) a file to the server.

DELE

Delete a file on the server.

QUIT

Close the FTP session and disconnect.

FTP vs HTTP

While both FTP and HTTP can transfer files, they serve different purposes. FTP is optimised for bulk file transfers and directory management between systems, while HTTP is designed for delivering web content (HTML pages, images, APIs). Today, HTTP/HTTPS has largely replaced FTP for browser-based downloads, but FTP and SFTP remain widely used in server administration, software deployment, and hosting workflows.
