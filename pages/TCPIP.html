The TCP/IP Model (4 Layers)

The TCP/IP model organises network communication into four conceptual layers, each responsible for specific functions:

Layer 4 — Application

Where user-facing protocols operate: HTTP, HTTPS, FTP, DNS, SMTP, SSH. This is where browsers and applications interact with the network.

Layer 3 — Transport

Manages end-to-end communication. TCP provides reliable, ordered delivery. UDP provides fast, connectionless delivery.

Layer 2 — Internet

Handles logical addressing and routing using IP addresses. The IP protocol operates here, routing packets across networks.

Layer 1 — Network Access

Covers the physical transmission of data: Ethernet, Wi-Fi, MAC addresses, and the physical cables or wireless signals.

TCP: How Reliable Delivery Works

TCP guarantees reliable delivery through a process called the Three-Way Handshake before any data is transmitted:

The Three-Way Handshake

  • SYN — Client sends a synchronise packet to the server: "I want to connect."
  • SYN-ACK — Server responds with synchronise-acknowledge: "Connection accepted."
  • ACK — Client sends an acknowledgement: "Connection established." Data transfer begins.

TCP also handles error detection, packet reordering, and flow control, ensuring data arrives complete and in the correct sequence.

IP Addressing

IPv4

32-bit address written as four octets (e.g., 192.168.1.1). Supports ~4.3 billion unique addresses — now exhausted.

IPv6

128-bit address written in hexadecimal (e.g., 2001:0db8::1). Supports virtually unlimited addresses.

TCP vs UDP

TCP: reliable, ordered, slower. UDP: faster, connectionless, no delivery guarantee — used in video streaming, gaming, VoIP.

Packets

Data is broken into small chunks called packets. Each travels independently across the network and is reassembled at the destination.
