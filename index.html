The World Wide Web

The World Wide Web (WWW) is an information system that operates over the Internet, allowing documents and resources to be interlinked through hyperlinks and accessed via web browsers. It was invented by British scientist Sir Tim Berners-Lee in 1989 while working at CERN, and was made publicly available in 1991.

The Web is not the same as the Internet. The Internet is the underlying global network infrastructure (cables, routers, data centres), while the World Wide Web is a service that runs on top of it — a vast collection of web pages and multimedia content stored on web servers worldwide.

The original World Wide Web logo designed by Robert Cailliau, co-developer of the Web alongside Tim Berners-Lee.

Core Components of the Web

  • URL — a unique address that identifies every resource on the Web
  • HTTP/HTTPS — the protocol used to transfer web pages between servers and browsers
  • HTML — the markup language used to structure content on web pages
  • Web Browser — the software used to access and display web content
  • Web Server — the computer that hosts and serves web pages to clients

HyperText Markup Language (HTML)

HTML is the standard markup language for creating web pages. It describes the structure of a web page using a series of elements represented by tags. Browsers read HTML documents and render them as visible web pages.

HTML was first proposed by Tim Berners-Lee in 1991. The current standard is HTML5, maintained by the World Wide Web Consortium (W3C) and WHATWG. HTML works hand-in-hand with CSS (for styling) and JavaScript (for interactivity).
